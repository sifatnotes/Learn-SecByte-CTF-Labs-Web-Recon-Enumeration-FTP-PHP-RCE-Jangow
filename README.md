## Categories

### 1. Web Recon & Discovery

The web reconnaissance labs focus on identifying application footprints, directories, listings, and hidden web resources. **Feroxbuster Trail**, **Listing Leak**, and **Enumerate the Hidden Web** provide practice with structured web enumeration.

### 2. Network & Service Enumeration

**Flashscan Nmap Sprint** and the broader enumeration labs emphasize network and service discovery as an important stage of security assessment.

### 3. FTP Security

The FTP-focused exercises cover anonymous FTP and FTP-related access workflows. These scenarios help learners understand why exposed services and weak access controls require careful security assessment.

### 4. PHP RCE

**PHP RCE Drift** focuses on a PHP-based remote code execution scenario. The lab can be used to understand how application weaknesses may lead from web exposure toward code execution in an authorized environment.

### 5. Jangow Labs

The two Jangow links are preserved separately as supplied:

- **Jangow Enum Lab**
- **Jangow Enumeration Lab**

Their URLs indicate an emphasis on enumeration.

## Learning Path

A practical sequence for these **hands-on cybersecurity labs** is:

1. Begin with **Recon Riddle Find Web Footprint** to develop web reconnaissance habits.
2. Practice directory and content discovery with **Feroxbuster Trail** and **Listing Leak**.
3. Continue with **Enumerate the Hidden Web**.
4. Learn network discovery using **Flashscan Nmap Sprint**.
5. Practice broader enumeration with **Enumerate All the Things**.
6. Explore FTP exposure through **Anonymous FTP Pivot** and **FTP First Shell Later**.
7. Apply enumeration toward a compromise scenario with **Enumerate to Compromise**.
8. Study **Jangow Enum Lab** and **Jangow Enumeration Lab**.
9. Finish with **PHP RCE Drift** to connect web reconnaissance with an RCE-oriented vulnerability scenario.

## How to Use the Labs

- Use the labs only within authorized training environments.
- Read the objectives and scope before testing.
- Start with passive or low-impact reconnaissance where appropriate.
- Record discovered hosts, services, directories, parameters, and technologies.
- Treat enumeration as a structured process rather than random scanning.
- For FTP exercises, examine exposure and access-control implications.
- For PHP RCE exercises, focus on understanding the underlying vulnerability and its defensive mitigations.
- Document findings and remediation ideas after each lab.
